# Proyectos de ATPDraw para el catálogo

Deje aquí sus proyectos de ATPDraw guardados como XML
(*File → Save As → XML text format*). Cada vez que se use `power-studies` con ATPDraw
(`exportar --herramienta atpdraw` o `atpdraw-catalogo`), los archivos nuevos o
modificados se incorporan solos al catálogo de componentes.

Otras carpetas se agregan con la variable de entorno `POWER_STUDIES_ATPDRAW`
(separadas por `;` en Windows). Guía completa: [`docs/atpdraw.md`](../../docs/atpdraw.md).
