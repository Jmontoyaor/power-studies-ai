# Plantillas

Archivos nativos de cada herramienta con marcadores `{{VARIABLE}}` (o
`{{VARIABLE|ancho}}` en formatos de columnas fijas como ATP). Ver
`docs/herramientas.md`. Lista de variables de un modelo:

    power-studies exportar red.yaml --herramienta atp --salida tmp/   # -> variables_atp.csv
